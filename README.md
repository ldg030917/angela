# Angela 도서 실물조사

과거 Excel 장부와 실제 책 한 권씩을 구분해 조사하는 Windows PC 프로그램과 오프라인 Android 앱입니다. 두 기기는 조사 파일과 결과 JSON을 USB 케이블이나 파일 전송 수단으로 주고받으며 같은 네트워크나 인터넷 주소가 필요하지 않습니다. 원본 Excel은 수정하지 않습니다.

## 데이터 원칙

- Excel의 한 행은 `legacyRecords`에 원문·시트명·행 번호와 함께 저장합니다. 권수나 비고를 실물 여러 권으로 자동 분해하지 않습니다.
- 실제 책 한 권은 `physicalBooks`의 `physicalId`로 관리합니다. `legacyLedgerId`는 별도의 과거 장부 참조값입니다. 두 번호가 같아야 할 필요가 없습니다.
- 새 번호는 `issuedIds`에 남은 해당 연도의 최고 번호 다음으로 발급합니다. `DISCARDED`·`LOST` 상태로 바뀌어도 실물 기록과 발급 이력은 유지합니다.
- 제목과 출판사의 `Raw`, `Canonical`, `Search` 값을 구분합니다. 원문은 보존하고, 화면 표시와 검색에 안전한 정규화를 적용합니다.
- 과거 JSON 형식의 `books`는 시작 시 장부 기록으로 마이그레이션합니다. 과거 행의 번호를 실물번호로 가정하지 않습니다. 기존 v1 조사 세션은 보존하되 새 조사는 v2 형식으로 만들어야 합니다.

## 작업 순서

1. `번호` 또는 `등록번호`, `도서명`, `권수` 열이 있는 `.xls` 또는 `.xlsx`를 가져옵니다. 첫 20행에서 헤더를 찾고 해당 형식의 모든 시트를 읽습니다. `날짜`/`등록일`, `출판사`, `비고`, `저자`, `위치`는 있으면 함께 보존합니다. 번호만 미리 채운 빈 양식 행은 건너뜁니다.
2. PC에서 조사본을 만들고 `Android 앱용 조사 파일 다운로드`로 JSON을 받습니다. 앱 APK도 PC에서 내려받아 휴대전화로 옮깁니다.
3. 실물번호 또는 제목으로 찾습니다. 실물번호가 없으면 `번호 없음 / 훼손`을 선택해 임시 ID로 기록합니다. 과거 장부 연결과 유사 도서 후보는 작업자가 선택합니다.
4. 모바일 조사 JSON을 저장하거나 Android 공유창으로 PC에 전달합니다. PC에서 여러 결과 JSON을 한꺼번에 선택해 파일별로 번호 불일치, 중복 후보, 조사 중 발생한 변경, 미식별 항목을 검토합니다. 미식별 책은 보류해 검토 큐에 남길 수 있습니다.
5. 검토 후 새 실물번호를 발급합니다. 결과 Excel은 도서번호·입수일·도서명·권 번호·출판사·비고·실물 상태 일곱 열로 저장하며 도서번호 오름차순으로 정렬합니다. 실물조사를 하지 않은 과거 장부의 책도 `상태 미확인`으로 포함합니다. 과거 장부와 연결된 실물의 입수일이 비어 있으면 원본 장부 날짜를 사용합니다. 원본에도 날짜가 없으면 빈칸으로 남깁니다.

## PC에서 실제 사용

1. [Windows 실행 파일 묶음](dist/Angela-Windows-20260929.zip)을 내려받아 폴더째 압축 해제하고 그 안의 `Angela.exe`를 더블클릭합니다. 업데이트 후에는 실행 중인 이전 Angela를 종료한 뒤 새 묶음에서 다시 실행합니다. 관리 창을 닫으면 프로그램과 로컬 서버도 종료됩니다. 실행 중 다시 열어도 두 번째 창이나 서버는 생기지 않습니다. 트레이에는 Android 앱과 같은 아이콘이 표시됩니다. 터미널이나 별도 Node.js 설치가 필요하지 않습니다. `.xls`와 `.xlsx`는 Microsoft Excel 설치 없이 읽습니다.
2. `Excel 파일 열기`에서 원본 `.xls` 또는 `.xlsx` 장부를 선택합니다. 원본 장부는 빈 원장에 한 번만 가져올 수 있습니다. 이 프로그램이 만든 결과 `.xlsx`를 다시 불러올 때는 바로 아래 `결과 Excel 가져오기`를 사용합니다. 기존 데이터와 같은 번호·내용은 유지하고 새 실물 또는 미확인 장부 행만 추가합니다. 같은 번호의 내용이 다르면 전체 가져오기를 중단하므로 PC 실물 편집이나 조사 반영에서 수정하세요. 결과 Excel의 비고는 원본 장부의 후원사·기업 기록을 보존하며 빈칸이어도 됩니다. 결과 Excel만으로 원본 장부의 시트·권수 원문과 조사 이력을 복원할 수는 없습니다. 테스트 데이터를 모두 지우려면 PC의 원장 초기화를 누르고 확인창에 초기화를 입력하세요. 기존 원장은 데이터 폴더의 catalog-backup-*.json으로 자동 백업한 뒤 과거 장부·실물·조사 기록을 비웁니다. 그 다음 원본 Excel을 다시 가져올 수 있습니다. Android에 남아 있는 이전 조사 파일은 새 원장에 사용하지 마세요. `작업자`와 `조사 구역`을 입력하고 `조사용 데이터 생성`을 누른 뒤 `Android 앱용 조사 파일 다운로드`에서 `survey-package-....json`을 PC에 저장합니다. `Android 현장조사 앱 다운로드`에서 APK도 받습니다.
3. `새 실물 Excel 일괄 추가`에서 기존 장부 형식 `.xls`/`.xlsx`를 선택하고 시트명(필요할 때만), 시작·끝 행을 입력합니다. `추가할 책 미리 확인`에서 건수와 앞·뒤 행을 확인한 다음 `확인한 ...권 추가`를 누릅니다. Excel의 `번호`를 실물번호로 그대로 쓰고 `날짜`·`도서명`·`출판사`·`비고`를 옮깁니다. 기존 실물은 수정하지 않으며, 번호 중복이나 행 오류가 하나라도 있으면 전체 추가를 중단합니다. 파일을 선택하면 즉시 읽어 메모리에 보관합니다. 읽기 오류가 나면 파일을 PC의 로컬 폴더에 복사한 뒤 다시 선택하세요. `.xls`도 Excel 없이 직접 읽습니다.
4. PC의 실물 목록에서 새로 들여온 책 등록을 눌러 입수일·도서명·권 번호(선택)·출판사·매수와 번호 연도를 입력할 수 있습니다. 매수만큼 고유한 실물번호가 자동 발급됩니다. 실물 목록에서 각 책의 권 번호를 확인할 수 있고, 기존 실물 행의 편집을 눌러 번호·입수일·도서명·권 번호·출판사·비고·상태를 수정할 수 있습니다. 실물 목록과 과거 장부 목록은 검색어를 입력했을 때만 나타나며 각각 최대 100건을 보여줍니다. 실물 목록에는 연결된 장부의 비고가 함께 표시됩니다. 특정 실물의 비고를 따로 수정하거나 빈칸으로 지우면 그 책의 결과 Excel에도 그대로 반영됩니다. 과거 장부 목록의 `비고 수정`으로 원본 장부 비고를 바꾸면 별도 비고를 설정하지 않은 연결 실물에도 반영됩니다. 번호는 다른 책에서 이미 발급된 번호와 중복될 수 없습니다.
5. 현장 조사 JSON을 PC로 옮겨 `조사 결과 불러오기`에서 한 개 이상 선택합니다. 각 파일의 `충돌·중복 검사`를 누르면 검토할 책이 도서명·출판사·기존 번호·조사 번호와 함께 한 권씩 팝업으로 열립니다. 기본 처리로 괜찮으면 확인 후 다음 옆의 Enter 표시처럼 Enter 키를 눌러 다음 항목으로 넘어갑니다. 입력칸에서도 Enter 키로 같은 확인 동작을 실행합니다. 번호 없는 책은 `신규 실물번호 발급`, 저장 번호와 실제 번호가 다른 책은 `변경 적용`이 기본값입니다. 확실하지 않다고 표시한 책은 `보류`가 기본값입니다. 필요하면 처리 방법과 최종 번호를 바꾸거나 `이전`으로 돌아갑니다. 모든 항목을 확인한 뒤 `최종 반영`을 누릅니다. 이미 발급된 번호는 반영되지 않으며 보류 항목은 아래 `검토 필요`에서 처리합니다. 같은 결과를 다시 가져오면 추가·수정된 항목만 검토하고, 달라진 항목이 없으면 다음 파일로 넘어갑니다.
6. `결과 Excel 저장`에서 저장 위치와 파일명을 선택합니다. 결과에는 확인된 실물과 아직 확인하지 않은 과거 장부 책이 함께 들어가며, 실물별 권 번호와 원본 비고(후원사·기업 기록)를 보존합니다. 이전 형식의 결과 Excel에 권 번호 열이 없으면 빈칸으로 가져옵니다. 비고가 없는 책은 빈칸으로 둡니다. 같은 책에 서로 다른 실물번호가 있으면 번호별로 한 행씩 기록하며 `매수` 열은 없습니다. 취소하면 원장은 그대로 유지됩니다. 원본 Excel을 자동 덮어쓰지 않습니다. PC 원장은 `%LOCALAPPDATA%\Angela\data\catalog.json`에 저장되므로 정기적으로 이 파일을 백업하세요. 이전 개발용 `data/catalog.json`이 있고 새 저장소가 비어 있을 때는 처음 실행 시 복사합니다. 원본 Excel과 현장 JSON은 Git에 넣지 마세요.

## Android 휴대전화에서 실제 사용

1. PC에서 받은 [Angela 오프라인 Android 앱](dist/Angela-offline-android.apk)과 `survey-package-....json`을 USB 케이블 또는 파일 전송 수단으로 휴대전화에 복사합니다. Android 8.0 이상에서 APK를 열어 설치합니다. 처음 설치할 때는 휴대전화가 파일 관리자에 대해 `알 수 없는 앱 설치`를 허용하라는 안내를 표시할 수 있습니다. 이 APK는 내부 사용용 디버그 서명 빌드이며 Play 스토어 앱은 아닙니다.
2. 홈 화면의 `Angela 현장조사` 앱을 열고 `PC에서 받은 조사 파일 열기`에서 JSON을 선택합니다. Wi-Fi 연결, PC 서버 접속, 인터넷 주소 입력이 필요하지 않습니다. 앱은 인터넷 권한을 요청하지 않습니다.
3. 번호 없음 / 훼손 화면 또는 조사 화면에서 새로 들여온 책 등록을 선택할 수 있습니다. 입수일·도서명·권 번호(선택)·출판사·매수를 입력하며, 도서명 목록 자동완성은 없고 출판사는 입력창 아래 추천만 표시됩니다. 연도별 예상 번호가 매수만큼 표시되며 PC 반영 시 현재 원장 번호를 기준으로 최종 확정합니다. 서로 다른 시리즈 권은 권 번호를 각각 입력해 별도로 등록하세요. 같은 권의 여러 부수만 매수로 입력합니다. 실물번호 8자리만 입력해도 `YYYY-NNNN`으로 표시·검색됩니다. 기존 실물을 고르면 `기존 항목이 맞음`, `정보가 다름`, `실물 번호 수정`을 선택할 수 있습니다. 같은 제목의 다른 책이라면 `다른 책 / 신규 실물`, 판단이 어려우면 `확실하지 않음 / PC 검토`를 선택합니다. 과거 장부 후보는 각 행의 `연결` 버튼으로 지정합니다. 입수일은 조회만 가능합니다. 기록은 앱에 자동 저장되며 최근에 휴대전화에서 받은 조사 파일부터 목록 맨 위에 표시됩니다. `조사 계속하기`로 이어갈 수 있습니다. 조사가 끝나고 결과 JSON을 별도로 저장·전달했다면 목록의 `이 조사 기록 삭제`를 누르세요. 해당 조사에 저장된 권수를 확인하고 확인창에 `삭제`를 입력해야 휴대전화 기록이 제거됩니다.
과거 장부 후보에서 `연결`을 누른 뒤 책에 적힌 실제 실물번호를 입력하면 `과거 장부와 연결/실제 번호 수정`이 기본 선택됩니다. 같은 장부에 연결되고 권 번호가 맞거나 제목·출판사·권 번호가 정확히 일치하는 기존 실물이 한 권이면 그 책이 자동 선택됩니다. 후보가 여러 권이거나 제목이 비슷한 책만 있을 때는 같은 책의 기존 실물을 직접 고르거나 `같은 책의 기존 실물 없음 · 새 실물 생성`을 선택합니다. 기존 실물을 선택하면 저장 번호가 실제 번호와 다를 경우 번호 변경 요청으로, 같으면 기존 기록의 장부 연결·정보 확인으로 저장합니다. 기존 실물이 없으면 실제 번호로 새 실물을 기록합니다. 실제 번호가 다른 책에 이미 지정되어 있으면 저장을 막고, 번호 변경은 PC의 조사 결과 반영에서 최종 확인합니다.

4. `이번 조사 기록`의 각 책 오른쪽 `수정`을 눌러 도서명·출판사·상태·과거 장부 연결을 고치고 저장합니다. 과거 장부 연결란에는 도서명이 미리 검색되어 후보가 표시되며, 도서명이나 장부번호로 다시 검색해 원하는 행의 `연결`을 누를 수 있습니다. 현재 연결된 행은 따로 표시되고 `연결 해제`로 지울 수 있습니다. 번호가 있는 책은 실물번호도 고칠 수 있습니다. 새로 들여온 책은 입수일을 고칠 수 있으며 번호는 PC 반영 시 확정하므로 수정 화면에서 잠겨 있습니다. 수정한 기록은 기존 항목을 대체합니다. `결과 저장`을 눌러 Android 파일 선택기에서 JSON 저장 위치를 고르거나 `공유`를 눌러 시스템 공유창에서 파일을 전달합니다. 공유를 취소해도 조사 기록은 그대로 남습니다. PC에서는 받은 `survey-result-....json`을 `조사 결과 불러오기`에서 엽니다. PC에 이미 반영한 조사 기록을 수정했다면 결과 JSON을 다시 저장해 가져옵니다. 바뀐 실물번호는 PC의 순차 확인창에서 최종 승인하며 기존 책을 중복 생성하지 않습니다. 팝업에서 Android 뒤로가기를 누르면 팝업이 닫히고, 최상위 화면에서는 2초 안에 두 번 눌러야 종료됩니다.

앱 안의 기록은 앱 제거·앱 데이터 삭제 시 사라질 수 있습니다. 조사 중간에도 결과 파일을 저장해 별도로 보관하세요. PC와 Android 앱은 자동 동기화되지 않습니다. 업데이트용 APK를 다른 개발 컴퓨터에서 빌드하면 서명 키가 달라 기존 앱 위에 설치되지 않을 수 있으므로, 이 경우 먼저 결과 JSON을 저장해야 합니다.

Android 소스는 `android-app/`에 있습니다. JDK 17과 Android SDK 35가 설치된 PC에서 `cd android-app` 후 `gradle packageForPc`로 APK를 다시 빌드하면 `dist/Angela-offline-android.apk`도 갱신됩니다. Windows 프로그램 묶음은 프로젝트 폴더에서 `./scripts/build-windows.ps1`로 다시 만듭니다. 개발용 실행은 `./start.ps1`이며 Node.js가 필요합니다. PC 화면의 앱 다운로드 링크는 빌드된 APK를 제공합니다.

공유창은 Android 에뮬레이터에서 JSON 파일 첨부까지 확인했습니다. 휴대전화 제조사별 공유 대상 앱, 실제 Windows PC에서의 Edge 앱 창과 저장 대화상자, 실제 기기 APK 설치는 현장 환경에서 한 번 더 확인해야 합니다. Windows 실행 파일 묶음은 압축 해제한 폴더 구조를 그대로 유지해야 합니다.
