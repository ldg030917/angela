# Angela 도서 실물조사

과거 Excel 장부와 실제 책 한 권씩을 구분해 조사하는 로컬 웹 프로그램입니다. Windows PC에서 `./start.ps1`로 실행하고 <http://127.0.0.1:4173>에서 엽니다. Node.js 22 이상을 권장합니다. `.xls` 원본을 가져올 때는 Microsoft Excel이 PC에 설치되어 있어야 합니다. `.xlsx`는 Excel 없이 읽을 수 있습니다. 원본 파일은 수정하지 않습니다.

## 데이터 원칙

- Excel의 한 행은 `legacyRecords`에 원문·시트명·행 번호와 함께 저장합니다. 권수나 비고를 실물 여러 권으로 자동 분해하지 않습니다.
- 실제 책 한 권은 `physicalBooks`의 `physicalId`로 관리합니다. `legacyLedgerId`는 별도의 과거 장부 참조값입니다. 두 번호가 같아야 할 필요가 없습니다.
- 새 번호는 `issuedIds`에 남은 해당 연도의 최고 번호 다음으로 발급합니다. `DISCARDED`·`LOST` 상태로 바뀌어도 실물 기록과 발급 이력은 유지합니다.
- 제목과 출판사의 `Raw`, `Canonical`, `Search` 값을 구분합니다. 원문은 보존하고, 화면 표시와 검색에 안전한 정규화를 적용합니다.
- 과거 JSON 형식의 `books`는 시작 시 장부 기록으로 마이그레이션합니다. 과거 행의 번호를 실물번호로 가정하지 않습니다. 기존 v1 조사 세션은 보존하되 새 조사는 v2 형식으로 만들어야 합니다.

## 작업 순서

1. `번호` 또는 `등록번호`, `도서명`, `권수` 열이 있는 `.xls` 또는 `.xlsx`를 가져옵니다. 첫 20행에서 헤더를 찾고 해당 형식의 모든 시트를 읽습니다. `날짜`/`등록일`, `출판사`, `비고`, `저자`, `위치`는 있으면 함께 보존합니다. 번호만 미리 채운 빈 양식 행은 건너뜁니다.
2. PC에서 조사본을 만들고 모바일 화면을 엽니다. 파일로 전달할 때는 `조사용 JSON 저장`을 사용합니다.
3. 실물번호 또는 제목으로 찾습니다. 실물번호가 없으면 `번호 없음 / 훼손`을 선택해 임시 ID로 기록합니다. 과거 장부 연결과 유사 도서 후보는 작업자가 선택합니다.
4. 모바일 조사 JSON을 저장해 PC에 가져옵니다. PC에서 번호 불일치, 중복 후보, 조사 중 발생한 변경, 미식별 항목을 검토합니다. 미식별 책은 보류해 검토 큐에 남길 수 있습니다.
5. 검토 후 새 실물번호를 발급합니다. 결과 Excel에는 `실물원장`, `과거장부`, `폐기기록` 시트가 들어갑니다.

## PC에서 실제 사용

1. Windows PowerShell에서 프로젝트 폴더로 이동해 `./start.ps1`을 실행합니다. PC 브라우저에서 <http://127.0.0.1:4173>을 열고 `과거 Excel 가져오기`에 원본 파일을 선택합니다. 가져오기는 빈 데이터베이스에 한 번만 할 수 있습니다. 기존 `data/catalog.json`이 있다면 먼저 백업하고 현재 데이터인지 확인하세요.
2. `작업자`와 `조사 구역`을 입력하고 `조사용 데이터 생성`을 누릅니다. `조사용 JSON 저장`으로 기준본을 보관할 수도 있습니다.
3. 현장 조사 JSON을 PC로 옮긴 뒤 `조사 결과 반영`에서 선택합니다. `충돌·중복 검사`의 각 검토 항목을 결정하고 반영합니다. 화면의 `검토 필요` 항목도 확인한 뒤 `결과 Excel 생성`으로 `.xlsx`를 받습니다.
4. PC 원장은 `data/catalog.json`에 저장됩니다. 작업을 마칠 때 이 파일을 별도로 백업하세요. 원본 Excel, `data/` 및 현장 조사 JSON은 Git에 넣지 마세요.

## 휴대전화에서 실제 사용

1. 휴대전화와 PC를 같은 신뢰할 수 있는 Wi-Fi에 연결합니다. PC PowerShell에서 `$env:HOST='0.0.0.0'; ./start.ps1`로 서버를 켭니다. `ipconfig`에서 PC의 Wi-Fi IPv4 주소를 확인합니다. Windows 방화벽이 물으면 해당 사설 네트워크 접근을 허용해야 합니다. 인터넷 연결은 필요하지 않지만 PC 서버와 같은 로컬 네트워크는 필요합니다.
2. PC에서 조사본을 생성한 뒤 휴대전화 브라우저에 `http://PC의IPv4주소:4173/mobile`을 입력합니다. `조사용 JSON 저장` 파일을 휴대전화로 옮겨 `조사용 JSON 열기`에서 선택하거나, PC의 조사 링크에서 `127.0.0.1`을 PC IPv4 주소로 바꾼 `/mobile?session=...` 주소를 엽니다.
3. 휴대전화에서 번호 또는 제목을 검색하고 실제 책을 한 권씩 기록합니다. 화면의 저장 기록은 그 휴대전화 브라우저의 로컬 저장소에 남습니다. 같은 브라우저를 사용하고 조사 중 사이트 데이터 삭제·시크릿 모드 사용은 피하세요.
4. 조사를 마치면 `조사 JSON 저장`을 눌러 결과 파일을 휴대전화에 다운로드합니다. USB, 파일 공유 등으로 PC에 옮겨 위 PC 절차의 3단계를 진행합니다. 조사 JSON을 PC에 반영하기 전까지 휴대전화의 기록과 PC 원장은 자동으로 합쳐지지 않습니다.

기본 실행은 PC 자신만 접속할 수 있는 `127.0.0.1`로 제한됩니다. 휴대전화 접속을 위해 `0.0.0.0`으로 열 때는 신뢰하는 사설 네트워크에서만 사용하세요. 현재 계정 인증과 PC 없이 휴대전화 단독으로 페이지를 여는 완전 오프라인 모드는 없습니다.
