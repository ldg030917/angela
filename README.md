# Angela 도서 실사

PC 원장과 모바일 조사 화면을 제공하는 로컬 웹 프로그램입니다. 기존 코드나 별도 PC 프로그램이 없는 빈 작업 폴더에서 구현했습니다.

## 실행

현재 PC에서는 `C:\Projects\Angela`에서 `node server.mjs` 또는 `./start.ps1`을 실행하고 http://127.0.0.1:4173 에 접속합니다. `npm start`도 동일합니다.

Node 22 이상과 Codex 번들의 `@oai/artifact-tool` 2.8.59를 사용합니다. 현재 `node_modules`는 Codex 번들 패키지 폴더에 연결되어 있습니다. 이 환경에서는 `npm install`을 실행하지 않습니다. 다른 PC로 옮길 때는 동일 번들 패키지를 연결하거나 Excel 어댑터를 교체해야 합니다.

## 작업 순서

1. **샘플 Excel 다운로드**로 샘플 파일을 받고 **Excel 원장 파일**에서 선택합니다. `.xlsx` 첫 시트에 등록번호·도서명·저자·위치·권수 열이 필요합니다. 등록번호는 중복 없는 YYYY-NNNN입니다.
2. **조사용 데이터 생성** → **모바일 조사 화면 열기**로 이동합니다. 조사용 JSON도 다운로드할 수 있고 `/mobile`의 파일 선택으로 다시 열 수 있습니다.
3. 도서를 검색해 **실물 확인**, **권수 변경**, **폐기 기록**, **신규 도서 추가**를 실행합니다. 폐기는 현재 권수를 감소시키며 수량·사유·일시를 별도로 보존합니다.
4. **조사 JSON export** → **JSON 파일 저장**으로 결과를 받습니다.
5. PC 화면의 **조사 결과 파일**에서 JSON을 선택하고 **충돌 검사**를 실행합니다. 조사 시작 뒤 변경된 도서는 PC 유지 또는 조사 결과 반영을 명시적으로 선택합니다. PC 유지 시 해당 도서의 폐기 기록도 반영하지 않습니다.
6. **원장 반영 · 신규 번호 발급**을 누르면 선택 연도에서 사용 중인 가장 큰 번호 다음부터 발급합니다. 같은 조사는 한 번만 반영되며 이후에는 새 조사를 생성합니다.
7. **결과 Excel 생성**으로 원장과 폐기기록 시트를 다운로드합니다. 폐기기록의 일시는 UTC 기준입니다.

## 저장과 실행 범위

- PC 원장·조사 기준본·반영 이력은 `data/catalog.json`에 원자적 파일 교체 방식으로 저장됩니다. 서버를 재시작해도 유지됩니다.
- 모바일 기록은 해당 브라우저·사이트의 localStorage에 저장됩니다. 같은 주소에서 페이지를 닫고 다시 열어 계속할 수 있습니다. 다른 브라우저나 기기로 자동 동기화되지 않으므로 JSON 파일로 전달합니다.
- 조사 중 화면은 기기 저장을 사용하지만, 화면 최초 로드·재로드와 JSON 파일 생성에는 서버 연결이 필요합니다. 완전 오프라인 앱은 아닙니다.
- 기본 실행은 이 PC의 127.0.0.1 전용입니다. 실제 휴대전화의 원격 접속·인증·배포는 이번 검증 범위에 포함되지 않았습니다. 모바일 검증은 실제 브라우저의 320/390px viewport로 수행했습니다.
- 기존 원장은 Excel 재업로드로 덮어쓰지 않습니다. 다른 원장을 별도로 시작하려면 PowerShell에서 `$env:DATA_DIR='data-other'`를 지정해 실행합니다.

## 검증

`npm test`는 충돌·중복 반영·수량 검증·연도별 번호·발급 한도 5개 테스트를 실행합니다.

`tests/verify-excel.mjs`는 브라우저에서 다운로드한 결과 파일의 도서 5종/13권, 신규 번호, 폐기 기록을 검증하고 두 시트를 렌더링합니다. 실행 예: `node tests/verify-excel.mjs "결과 파일 절대 경로"`.

실제 브라우저 테스트 기록은 `TEST_REPORT.md`, 화면 증빙은 `test-results`, 결과 파일은 `outputs/verification`에 있습니다. 현재 데이터는 검증에 사용한 샘플 원장입니다.
