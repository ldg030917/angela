# Angela 도서 실물조사

과거 Excel 장부와 실제 책 한 권씩을 구분해 조사하는 Windows PC 프로그램과 오프라인 Android 앱입니다. 두 기기는 조사 파일과 결과 JSON을 USB 케이블이나 파일 전송 수단으로 주고받으며 같은 네트워크나 인터넷 주소가 필요하지 않습니다. 원본 Excel은 수정하지 않습니다.

## 데이터 원칙

- Excel의 한 행은 `legacyRecords`에 원문·시트명·행 번호와 함께 저장합니다. 권수나 비고를 실물 여러 권으로 자동 분해하지 않습니다.
- 실제 책 한 권은 `physicalBooks`의 `physicalId`로 관리합니다. `legacyLedgerId`는 별도의 과거 장부 참조값입니다. 두 번호가 같아야 할 필요가 없습니다.
- 새 번호는 `issuedIds`에 남은 해당 연도의 최고 번호 다음으로 발급합니다. `DISCARDED`·`LOST` 상태로 바뀌어도 실물 기록과 발급 이력은 유지합니다.
- 제목과 출판사의 `Raw`, `Canonical`, `Search` 값을 구분합니다. 원문은 보존하고, 화면 표시와 검색에 안전한 정규화를 적용합니다.
- 과거 JSON 형식의 `books`는 시작 시 장부 기록으로 마이그레이션합니다. 과거 행의 번호를 실물번호로 가정하지 않습니다. 기존 v1 조사 세션은 보존하되 새 조사는 v2 형식으로 만들어야 합니다.

## 작업 순서

1. `번호` 또는 `등록번호`, `도서명`, `권수` 열이 있는 `.xls` 또는 `.xlsx`를 가져옵니다. 첫 20행에서 헤더를 찾고 해당 형식의 모든 시트를 읽습니다. `날짜`/`등록일`, `출판사`, `비고`, `저자`, `위치`는 있으면 함께 보존합니다. 번호만 미리 채운 빈 양식 행은 건너뜁니다.
2. PC에서 조사본을 만들고 `Android 앱용 조사 파일 다운로드`로 JSON을 받습니다. 앱 APK도 PC에서 내려받아 휴대전화로 옮깁니다.
3. 실물번호 또는 제목으로 찾습니다. 실물번호가 없으면 `번호 없음 / 훼손`을 선택해 임시 ID로 기록합니다. 과거 장부 연결과 유사 도서 후보는 작업자가 선택합니다.
4. 모바일 조사 JSON을 저장하거나 Android 공유창으로 PC에 전달합니다. PC에서 여러 결과 JSON을 한꺼번에 선택해 파일별로 번호 불일치, 중복 후보, 조사 중 발생한 변경, 미식별 항목을 검토합니다. 미식별 책은 보류해 검토 큐에 남길 수 있습니다.
5. 검토 후 새 실물번호를 발급합니다. 결과 Excel에는 `실물원장`, `과거장부`, `폐기기록` 시트가 들어갑니다.

## PC에서 실제 사용

1. [Windows 실행 파일 묶음](dist/Angela-Windows-20260928.zip)을 내려받아 폴더째 압축 해제하고 그 안의 `Angela.exe`를 더블클릭합니다. 관리 창을 닫으면 프로그램과 로컬 서버도 종료됩니다. 실행 중 다시 열어도 두 번째 창이나 서버는 생기지 않습니다. 트레이에는 Android 앱과 같은 아이콘이 표시됩니다. 터미널이나 별도 Node.js 설치가 필요하지 않습니다. `.xls` 원본을 가져올 때는 Microsoft Excel이 PC에 설치되어 있어야 합니다. `.xlsx`는 Excel 없이 읽을 수 있습니다.
2. `Excel 파일 열기`에서 실제 `.xls` 또는 `.xlsx`를 선택합니다. 빈 원장에 한 번만 가져올 수 있습니다. `작업자`와 `조사 구역`을 입력하고 `조사용 데이터 생성`을 누른 뒤 `Android 앱용 조사 파일 다운로드`에서 `survey-package-....json`을 PC에 저장합니다. `Android 현장조사 앱 다운로드`에서 APK도 받습니다.
3. 현장 조사 JSON을 PC로 옮겨 `조사 결과 불러오기`에서 한 개 이상 선택합니다. 각 파일의 `충돌·중복 검사`를 눌러 표의 기존 번호·조사 번호·상태를 비교하고 검토 항목을 결정합니다. 실물번호 변경은 여기서 최종 번호를 직접 입력할 수 있으며, 이미 발급된 번호는 반영되지 않습니다. 보류 항목은 아래 `검토 필요`에서 처리합니다.
4. `결과 Excel 저장`에서 저장 위치와 파일명을 선택합니다. 취소하면 원장은 그대로 유지됩니다. 원본 Excel을 자동 덮어쓰지 않습니다. PC 원장은 `%LOCALAPPDATA%\Angela\data\catalog.json`에 저장되므로 정기적으로 이 파일을 백업하세요. 이전 개발용 `data/catalog.json`이 있고 새 저장소가 비어 있을 때는 처음 실행 시 복사합니다. 원본 Excel과 현장 JSON은 Git에 넣지 마세요.

## Android 휴대전화에서 실제 사용

1. PC에서 받은 [Angela 오프라인 Android 앱](dist/Angela-offline-android.apk)과 `survey-package-....json`을 USB 케이블 또는 파일 전송 수단으로 휴대전화에 복사합니다. Android 8.0 이상에서 APK를 열어 설치합니다. 처음 설치할 때는 휴대전화가 파일 관리자에 대해 `알 수 없는 앱 설치`를 허용하라는 안내를 표시할 수 있습니다. 이 APK는 내부 사용용 디버그 서명 빌드이며 Play 스토어 앱은 아닙니다.
2. 홈 화면의 `Angela 현장조사` 앱을 열고 `PC에서 받은 조사 파일 열기`에서 JSON을 선택합니다. Wi-Fi 연결, PC 서버 접속, 인터넷 주소 입력이 필요하지 않습니다. 앱은 인터넷 권한을 요청하지 않습니다.
3. 실물번호 8자리만 입력해도 `YYYY-NNNN`으로 표시·검색됩니다. 기존 실물을 고르면 `기존 항목이 맞음`, `정보가 다름`, `실물 번호 수정`을 선택할 수 있습니다. 같은 제목의 다른 책이라면 `다른 책 / 신규 실물`, 판단이 어려우면 `확실하지 않음 / PC 검토`를 선택합니다. 과거 장부 후보는 각 행의 `연결` 버튼으로 지정합니다. 입수일은 조회만 가능합니다. 기록은 앱에 자동 저장되며 `조사 계속하기`로 이어갈 수 있습니다.
4. `결과 저장`을 눌러 Android 파일 선택기에서 JSON 저장 위치를 고르거나 `공유`를 눌러 시스템 공유창에서 파일을 전달합니다. 공유를 취소해도 조사 기록은 그대로 남습니다. PC에서는 받은 `survey-result-....json`을 `조사 결과 불러오기`에서 엽니다. 팝업에서 Android 뒤로가기를 누르면 팝업이 닫히고, 최상위 화면에서는 2초 안에 두 번 눌러야 종료됩니다.

앱 안의 기록은 앱 제거·앱 데이터 삭제 시 사라질 수 있습니다. 조사 중간에도 결과 파일을 저장해 별도로 보관하세요. PC와 Android 앱은 자동 동기화되지 않습니다. 업데이트용 APK를 다른 개발 컴퓨터에서 빌드하면 서명 키가 달라 기존 앱 위에 설치되지 않을 수 있으므로, 이 경우 먼저 결과 JSON을 저장해야 합니다.

Android 소스는 `android-app/`에 있습니다. JDK 17과 Android SDK 35가 설치된 PC에서 `cd android-app` 후 `gradle packageForPc`로 APK를 다시 빌드하면 `dist/Angela-offline-android.apk`도 갱신됩니다. Windows 프로그램 묶음은 프로젝트 폴더에서 `./scripts/build-windows.ps1`로 다시 만듭니다. 개발용 실행은 `./start.ps1`이며 Node.js가 필요합니다. PC 화면의 앱 다운로드 링크는 빌드된 APK를 제공합니다.

공유창은 Android 에뮬레이터에서 JSON 파일 첨부까지 확인했습니다. 휴대전화 제조사별 공유 대상 앱, 실제 Windows PC에서의 Edge 앱 창과 저장 대화상자, 실제 기기 APK 설치는 현장 환경에서 한 번 더 확인해야 합니다. Windows 실행 파일 묶음은 압축 해제한 폴더 구조를 그대로 유지해야 합니다.
